# Notes

## TSTerm Annual Review

Joe Devlin presented the TSTerm annual review.

## CRA Compliance

Materials were presented by John Mertic. Discussion ensued regarding mandatory cybersecurity requirements taking effect on September 11th, the Linux Foundation serving as the legal steward entity, updates to repository security files, and immediate escalation requirements for actively exploited vulnerabilities and severe security incidents.

Questions were raised and addressed regarding upstream dependency vulnerabilities and binary distribution remediation.

Mertic to upload compliance documentation to the TAC repository and distribute guidance via email to project leads.

## Infra Request \- Zcrafter AI MCP

An unsolicited infrastructure request for ZCrafter AI MCP was noted on the agenda. Since no representative was present to introduce the request, discussion was tabled.

Tom Slanda to contact the requester and invite them to present the proposal at a future meeting.

## Help with reviewing non-OMP project entries in the landscape

Mertic requested help from the community to review non-Open Mainframe Project entries on the Open Mainframe Landscape and an editorial review of a pull request for a landscape guide.

Project leads to review the Open Mainframe Landscape with their respective project groups.

## Open Discussion

Discussion ensued regarding outstanding infrastructure requests for z/VM Community Tools and automated VM Arc file generation using GitHub runners for REXX Execs.

Jeff Brown to copy Mertic on ongoing email communications regarding the z/VM Community Tools infrastructure request.
